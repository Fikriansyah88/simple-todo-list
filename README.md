## ✨ Features
- **Dark Mode Toggle**: Sleek dark mode for better accessibility and eye comfort.
- **Persistent Storage**: Uses `localStorage` so your tasks are saved even after closing the browser.
- **Task Filtering**: Easily filter tasks by 'All', 'Active', or 'Completed'.
- **Real-time Counter**: Keeps track of how many tasks you have left.
- **Full CRUD**: Add, Edit, Delete, and Mark tasks as completed with ease.
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop screens.
- **Smooth Animations**: Interactive UI with subtle micro-animations for a premium feel.

## 🛠️ Built With
- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Flexbox, and CSS Keyframe animations.
- **JavaScript (ES6+)**: Clean and modular logic using modern JS features.
- **Font Awesome**: Beautiful icons for a better visual experience.
- **Google Fonts**: 'Inter' font family for modern typography.

## 📦 How to Use Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Fikriansyah88/simple-todo-list.git
   ```
2. Open the folder:
   ```bash
   cd simple-todo-list
   ```
3. Open `index.html` in your browser.
